## Basic

손으로 찍은 듯 살짝 기울어진 도장입니다(`tilt`). 한 화면에 하나만 써야 도장의 힘이 삽니다. 글자는 한두 자(다온, 四柱)가 가장 잘 읽힙니다.

<Demo code={`import { FlexBox, SealBadge } from '@montage-ui/core';

const Demo = () => (
  <FlexBox gap="16px" alignItems="center">
    <SealBadge size="small">다온</SealBadge>
    <SealBadge>四柱</SealBadge>
    <SealBadge size="large" shape="square">다온</SealBadge>
    <SealBadge variant="outline" tilt={false}>命</SealBadge>
  </FlexBox>
);

export default Demo;`}
/>

## Props

| 이름 | 타입 | 설명 |
|:---|:---|:---|
| shape | `'round' \| 'square'` | 둥근 도장 또는 네모 낙관. 기본 round. |
| size | `'small' \| 'medium' \| 'large'` | 36·56·88px. |
| variant | `'solid' \| 'outline'` | 채움 또는 테두리. 기본 solid. |
| tilt | `boolean` | 손도장처럼 기울임. 기본 true. |
